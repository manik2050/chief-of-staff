## What is on main

The flagship is past the empty-default-branch problem. Recently landed:

- `/dispatch` writes file-native assignments under `work-log/` (owner, done-when,
  out-of-scope, status location). GitHub issues and PRs stay optional and still need a yes.
- Assignments carry a routing `tier` (`cost` / `balanced` / `intelligence`) and an explicit
  approval gate. Security, send, merge, and production work floor at intelligence. Approving
  the assignment is not approval to execute a side effect.
- pstack is enabled in-repo as the execution engine for agent owners. `/dispatch` names the
  playbook (`investigation` / `feature` / `interrogate`). CLAUDE.md §4 still outranks any
  playbook that would send or merge.
- The shipped `goals.yaml` is a generic TPM / operator example: public build, deep work,
  weekly status. Fiction. Not an employer plan. Replace it before a live `/gm`.

## Pattern

Treat routing as a file contract, not a vendored model-router. The assignment records the
lane. The runtime picks a cheap explicit model for cost-tier work. Do not dump a third-party
router, a dashboard, or another product's tree into this kit.
